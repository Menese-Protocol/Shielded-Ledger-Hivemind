The finished parameters are safe if even one contributor destroyed their secret honestly. You can be that one. That is the whole of the trust model, and it is why the chain below matters more than any assurance this page could give you.

Apply-and-destroy, after Bowe–Gabizon–Miers (2017). The secret never leaves this tab: the wasm module exposes only transform_contribution, which returns transformed public parameters and a public proof. There is no export that carries the secret, so no network call can.

On-chain acceptance runs structural checks only. The soundness-critical subgroup and pairing checks run off-chain, in the standalone verifier, over the published transcript — being appended here is not confirmation that your proof checked out.
